# Supply4u Revamped Website

Revamped, high-performance, studio-grade website for **Supply4u** (`www.supply4uapps.com`) by **Jarrod Avery**.

## ✨ What's New & Upgraded

1. **Dark Mode Studio Aesthetic**:
   - Modern developer-studio design system (inspired by Linear, Vercel, and Stripe) with ambient radial glows, glassmorphic bento cards, and responsive micro-interactions.
   - Tailored Plus Jakarta Sans & JetBrains Mono typography hierarchy.

2. **Dual Production Portfolio Showcase**:
   - **SlipStash**: Featured prominently as a production mobile app with authentic on-device screenshots (`screen_dashboard.jpg` and `screen_barcode.jpg`), feature badges (On-Device OCR, Dynamic Cashier Barcodes, Biometric Vault, CPA-Ready Reports), and live links to **Google Play** and `slipstashapp.com`.
   - **Serenity AI Wellness**: Highlighting the empathetic AI companion, local reflections, guided soundscapes/breathing, and Supabase/RevenueCat infrastructure with live **Google Play** store button.

3. **Interactive Project Cost & Scope Estimator**:
   - Prospective clients can self-select platforms (iOS, Android, Cross-platform, Web), key capabilities (Auth, AI/ML, In-App Payments, Cloud Sync, Admin Portals, Push Notifications), and delivery velocity.
   - Calculates real-time ballpark investment ranges and realistic sprint timelines.
   - **One-Click Form Prefill**: Clicking *"Apply to Project Request"* automatically populates their selections into the contact form below and smoothly scrolls down.

4. **Roadmap & Process Methodology**:
   - Clear 4-phase milestone journey: 01 Blueprint & Scope &rarr; 02 UI/UX Prototype &rarr; 03 Native Sprints &rarr; 04 Store Approval & Launch.

5. **Services Bento Grid & Tech Stack Showcase**:
   - Native mobile capabilities (SwiftUI, Kotlin Compose), MVP sprints, modern web apps (Next.js/React), on-device privacy, and AI LLM integrations.

6. **High-Converting Project Inquiry Form**:
   - Project type selector, budget tiers, scope notes, and mailto fallback directly to `info@supply4uapps.com`.

7. **Full Legal Compliance**:
   - Matching styled `privacy.html` and `terms.html` pages with `CNAME` for `supply4uapps.com`.

## 🌐 Deployment

### Option A: GitHub Pages
1. Push this folder to your GitHub repository (e.g., `github.com/Jrod647/supply4uapps.com`).
2. Go to **Settings &rarr; Pages** &rarr; Select `main` branch / `root`.
3. The included `CNAME` file will automatically bind `supply4uapps.com`.

### Option B: Cloudflare Pages / Vercel
- Drag and drop this folder or connect the Git repository. Zero build configuration required.
